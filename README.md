# 🏠 Aplikasi Prediksi Harga Kos Madiun

Mini Proyek Kelompok - Tema A: Aplikasi Prediksi Machine Learning.  
Proyek ini dibangun untuk memenuhi tugas mata kuliah praktikum, guna memprediksi estimasi harga sewa kos di wilayah Madiun berdasarkan fitur jarak ke kampus, rating, fasilitas AC, dan WiFi.

## 🔗 Tautan Aplikasi (Live Demo)
Akses aplikasi web interaktif yang telah di-deploy:  
👉 [Link Streamlit Cloud](https://prediksi-harga-kos-madiun-edmpuubsvgppntpkzoflt4.streamlit.app)

## 📁 Struktur Berkas di Repository
* `app_kos.py` : Berkas utama antarmuka web interaktif menggunakan Streamlit.
* `model_kos.joblib` : Berkas model Machine Learning regresi yang telah dilatih.
* `kos_madiun.csv` : Dataset asli referensi harga kos di Madiun.
* `requirements.txt` : Daftar pustaka/dependensi pustaka Python yang dibutuhkan.
